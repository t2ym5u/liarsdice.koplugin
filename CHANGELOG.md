# Changelog

## [1.0.4] - 2026-11-04

### Changed
- Uses less memory: the game loads when you open it, not when KOReader
  starts, so it no longer takes memory or startup time while unplayed.

## [1.0.3] - 2026-11-03

### Changed
- Picks up game-common 1.11.0: the shared on-screen keyboard (where used)
  gives every key the same letter size, and the no-repeat history helper.

## [1.0.2] - 2026-11-02

### Changed
- Picks up game-common 1.10.0: the shared Tools → Games menu also lists
  the games' new "· multiplayer" entries under Party & quiz.

## [1.0.1] - 2026-11-02

### Changed
- Listed under **Tools → Games**, grouped by category, instead of its own
  entry in the Tools menu (game-common 1.9.1).

## [1.0.0] - 2026-10-30

### Added
- First release: Liar's Dice for 2 to 6 players on one reader — bid, call Liar!, or (optionally) Exact!, with elimination down to the last player.
- Optional wild ones with the classic bidding rules for 1s.
- 0 to 5 computer players (probabilistic bidders that never bid illegally); no hand-over screens for computers or a lone human.
- Vector-drawn dice with pips; counting dice highlighted at the reveal.
- Player names remembered; game saved and resumed; "New game" in the action bar once the game is over.
